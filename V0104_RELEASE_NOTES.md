## CTA polish

Builder CTAs now use a restrained premium control system: 12px geometry, subtle depth, high-contrast primary actions, segmented EDIT / REHEARSE / TEACH treatment, tactile hover/press states, visible keyboard focus, and reduced-motion support. The patch intentionally avoids neon gradients and decorative AI styling.
